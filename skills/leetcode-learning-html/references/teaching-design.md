## 推荐学习路径

这是一条设计路径，不是强制解锁顺序。默认模板六个模块，可根据算法的认知难点改名或替换内容。

1. **概念诊断**：给一份小输入，要求预测结果、选择真正的状态或亲自执行一步。错误选项对应真实误解。
2. **反例与瓶颈**：运行一个会使天真模型失效的输入。区分“答案算错”和“性能不可接受”，不要用小输入伪称超时。
3. **心智模型与契约**：明确状态是什么、边界是什么、一次调用或迭代承诺什么、为什么可以丢弃或复用状态。
4. **真实状态轨迹**：逐步显示当前状态、改变的引用/表格/候选、操作依据、返回值或父帧等待。至少一个问题必须依赖当前帧中的具体数据。
5. **手填槽位**：将已理解的语义转成少量关键表达式；槽位标签解释作用，不透露表达式。检查保留用户写的错误内容，标明应复查的契约。
6. **独立重写与迁移**：收起早期骨架与代码轨迹。让学习者从签名重写；迁移题说明保留什么、改变什么、需要新增哪条证明，并提供自己的案例与签名。

## 如何选择表示

| 算法结构 | 应显示的状态 | 最有价值的操作/预测 |
| --- | --- | --- |
| 数组、哈希、前缀和 | 当前元素、已见集合/计数、前缀含义、查询与写入顺序 | 本轮应查什么；为什么不能先写入 |
| 双指针、滑窗 | 指针、区间约定、窗口量、合法条件、被淘汰区域 | 移哪一边；收缩前后窗口是否还合法 |
| 栈、队列、堆 | 逻辑结构、暴露位置、局部操作及不变量 | 下一次弹谁；局部有序是否等于整体有序 |
| 链表、树 | 节点身份、引用、缺失位置、当前帧、返回根/摘要 | 修改哪条边；先保存哪个引用；谁在等待 |
| 二分 | 候选集合、mid、谓词、闭/开边界 | 被删除的整段为何不可能包含答案 |
| 回溯 | 路径、候选、起始位置、撤销动作 | 哪个选择会重复；撤销恢复了什么 |
| 图、并查集 | 已访问集、前沿、邻接边、父代表/连通分量 | 何时标记；一次合并是否真的减少分量 |
| 动态规划 | 状态定义、依赖边、已完成表格、旧/新滚动变量 | 此刻读的是哪个位置；覆盖前哪个值仍要保留 |

不要用同一条“当前节点/当前值/下一步”假动画套所有题。矩阵、区间 DP 或双参数递归，需要相应的二维或双子树表示。

## 梯度图与框架实例

每份页面要回答“这道题处在什么能力层级”和“共同框架在本题具体长什么样”。梯度图可以是 3–5 个层级：基础操作→契约→本题新增决策→更一般的迁移。当前题高亮。相关题可只写题号与名称；只有对应目标真实存在时才提供本地链接。

框架至少覆盖：问题规模/候选、状态或函数契约、可观测操作、不变量、边界、答案位置、复杂度。用本题的对象和语义填写，不能只填“使用 DFS”“套二分模板”“定义 DP”。

## 轨迹和图形准确性

- 从实际执行生成帧，保留前态、操作、后态或清晰说明帧是操作前还是操作后。稀疏关键帧也必须能被执行结果证明。
- 案例标明用途：正常、边界、揭露误解。对合法输入域内的边界验证；不把非法输入悄悄当作题目要求。
- 树中 None 出现在相应父节点的真实孩子位置。双空必须有两个参数位置；单空不画出不存在的整棵子树。配对线连接实际比较的两端。
- 图/树节点身份与数值分开，重复数值不能合并节点。边界和节点标签避免重叠；图宽时只在图容器内滚动。
- 框架图、轨迹代码和参考解法属于阅读区域。独立编辑期间这些内容暂时收起。

## 练习质量

一题生成后应能回答：这页揭露了哪个误解？哪一步需要读当前可视状态？学习者必须自己写哪些表达式？独立重写时还能看到哪些参考？迁移改变了哪条契约？如果答案只是“读文字然后看代码”，重新设计。
