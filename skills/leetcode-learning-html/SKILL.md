# LeetCode 高效学习 HTML

将用户给出的题号、题目链接或完整题面，变成可以独立打开的学习页面。默认中文讲解、Python 解题代码、单文件离线 HTML；用户指定的语言和交付方式优先。

## 生成流程

1. 确认题意、签名、约束、示例与返回语义。题面完整时直接使用；只有题号或链接时读取对应官方题面。付费题或无法访问的题目不编造细节，先做可确认部分，仅对必要的缺失题意提问。
2. 阅读 [教学设计](references/teaching-design.md)，选出本题真正的认知变化：学习者从哪种错误模型，过渡到什么可证明的状态与决策。不要只按题目标签套六段讲义。
3. 先写并运行正确解法及轨迹生成器。至少覆盖正常案例、会揭露常见误解的反例、边界案例；核对最终结果、每步状态和复杂度。轨迹来自执行，而不是凭文字猜测。把对照解法或小规模穷举作为适用时的独立检查。
4. 按 [内容格式](references/content-schema.md) 编写题目专属 lesson JSON。推荐使用 `assets/lesson-shell.html`、`assets/lesson.css`、`assets/lesson.js`，通过 `scripts/build_lesson.py` 内嵌为单文件。模板支持数组/指针、树/图、状态表和手填槽位；不适合本题的视图可替换。仍须保留下面的交互约束。
5. 按 [验证流程](references/verification.md) 运行构建检查和浏览器验证，修复真实失败。展示最终 HTML 链接，说明已检查内容；不要声称未执行的代码验证已通过。

```text
python <skill目录>/scripts/build_lesson.py lesson.json --output leetcode_704_learning.html
node <skill目录>/scripts/verify_lesson.cjs leetcode_704_learning.html --browser <Chrome可执行路径> --playwright <Playwright模块路径>
```

使用当前环境的 Python、Node 和浏览器路径，不在生成页面中依赖这些路径。Playwright 已能从 Node 解析时省略 `--playwright`；浏览器有默认可用安装时省略 `--browser`。

## 跨编译器使用

本技能不绑定 Codex。Claude Code、Trae、Cursor、Cline、Aider 或其他代码助手都可以把本目录作为项目规则读取：复制整个目录，要求助手先阅读 `SKILL.md`，再按同目录的 `references/`、`assets/` 和 `scripts/` 生成并验证页面。若工具不支持技能目录，也可以直接按 README 的命令行流程运行 Python 构建器和 Node 验证器；生成结果与编辑器无关，是可以离线打开的单文件 HTML。

## 必须保留的交互约束

- **手动训练**：所有代码槽位初始为空；提示写槽位的作用，不写答案。独立编辑器初始只放公开签名和 `pass`，或为空。禁止一键填答、自动补槽，以及用正确答案兜底拼接未填槽位。
- **练习与参考分开**：代码轨迹、完整解法、已完成槽位代码，不能与独立编辑器同时显示。用明确的“查看参考”入口进入参考视图，暂时收起编辑器；返回时草稿原样保留。普通答题选项或提示按钮不得触发代码参考。
- **明确动作绑定**：使用独立 `data-action`/按钮 ID 绑定参考、答题、导航和检查。禁止按按钮文案包含“答案”“参考”“填入”推断动作，例如“当前 mid 就是答案”是答题选项。
- **自由进入**：推荐路径可提示学习顺序，但模块、迁移子模块、独立编辑器与代码检查不能依赖前面的完成状态。进入模块、查看参考都不计为掌握。
- **每次重新开始**：状态仅保留于本次页面的内存。不要使用 localStorage、sessionStorage、IndexedDB、cookie 或服务端恢复学习进度。刷新、重新进入或浏览器后退回到页面时，从初始状态开始；同一次页面内切换模块保留草稿。
- **错误可重试**：反馈说明当前状态的哪条证据不支持该选择；不给错误选项自动换成正确答案。不为完成一道题自动跳到别的模块或页面。
- **返回入口**：有课程主页且目标真实存在时显示返回主页；单独生成时显示回到题目概览，不造一个无效主页链接。
- **检查诚实**：槽位检查是表达式/语义约束检查；Python 独立代码若没有真实运行器，就提供清楚标注的自检清单，不能用关键词匹配宣布算法测试通过。可按需要增加真正的本地或浏览器执行能力，并验证测试结果。

## 交付范围

默认交付一道题的学习 HTML，可保留 lesson JSON 和轨迹生成器供后续修改。不要未经要求改动课程目录、旧学习页面或发布网站。新建页面无须复制历史学习记录或旧页面的大段通用补丁。

本技能抽取自用户的算法认知实验室；具体来源与可迁移设计见 [教学设计](references/teaching-design.md)。参考示范可运行 `scripts/demo_binary_search.py --output-dir <目录>`，它生成 #704 内容与可打开的 HTML，并验证参考算法；不要把 #704 的算法或知识阶梯照搬到其他题。
